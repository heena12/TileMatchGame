# Development Rules

1. Use React Native + TypeScript.

2. Never mix UI and Game Engine.

3. Game Engine must be pure TypeScript.

4. Every feature must follow:
   - Architecture explanation
   - File creation
   - Code implementation
   - Unit tests

5. Complete one phase before moving to next.

6. Do not use temporary shortcuts.

7. Write scalable production code.

8. Use SOLID principles.

9. Keep future support for:
   - 10000 levels
   - Multiplayer
   - Leaderboard
   - Cloud save
   - Ads
   - In-App Purchase
